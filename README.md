# TaskFlow ✨

TaskFlow is a modern, responsive productivity dashboard for organizing daily tasks, quick notes, and completed work in one focused workspace.

## Features

- Add, edit, delete, and complete tasks
- Organize tasks by category: Personal, Study, Work, Health, and Shopping
- Set due dates, reminders, priorities, and highlights
- Create quick notes and reminders
- Search tasks and notes
- Track daily completion progress
- Choose from multiple light and dark themes
- Optional sound feedback and celebration confetti
- Saves data automatically using browser local storage
- Responsive design for desktop and mobile devices

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- LocalStorage API
- Canvas API

## How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Start organizing your tasks and notes.

No installation or backend is required.
